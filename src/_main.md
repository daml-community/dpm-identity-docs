# `dpm-identity`
The `dpm-identity` repo is a store of identities and audits that is being implemented as a part of [this](https://github.com/canton-foundation/canton-dev-fund/blob/a51bd2127e5b4157afa1d364b0217f2063bb344d/proposals/2026-07-Obsidian-Package-Distribution.md) proposal.
The repository aims to manage identities and audits in a way that gives assurances that each identity is who they say they are, and each audit has come from a valid identity.
This will allow users to decide which auditors they trust statements from.
The identity store shouldn't make any guarantees about the security of artefacts generated by identities; this decision will be made by the users themselves via the tooling we provide in later milestones.

## Repository Objectives

Work on this repository can be split into two stages:

- **Milestone 1**: Create the repository with multi-key signoff enforced.
- **Milestone 7**: Ensure that the repository has mature governance processes that scale as the project expands.

This documentation currently satisfies **M1**, however we are currently working with **Digital Asset** to agree on the later governance processes, and we will highlight **M7** features wherever they are planned.
